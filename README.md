# DeSoto Auto Concierge - Client Intake Portal

Official web intake and client specification portal for **DeSoto Auto Concierge**, a Colorado-based private automotive acquisition and sales management firm.

## Features
- **Responsive Sourcing Portal**: Tailored multi-step mandate submission.
- **Pure Static Architecture**: Self-contained `index.html` file with zero build step required.
- **GitHub Pages Ready**: Instant deployment with standard GitHub Pages configuration.
- **Exclusive Email Point of Contact**: Configured exclusively for `CustomerSupport@DeSotoAC.com`.

## Deploying to GitHub Pages (100% Free)

1. Create a new repository on GitHub (e.g., `desoto-auto-concierge`).
2. Upload `index.html` and `README.md` to the root of the repository.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`.
5. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
